# api-tarefas
API de gerenciamento de tarefas (To-Do) construída com ASP.NET Core e C#.

Funcionalidades:
- CRUD completo de tarefas (criar, listar, atualizar, deletar)
- Validação de dados com Data Annotations
- Arquitetura em camadas (Controller, Service, DTO) seguindo princípios SOLID
- Injeção de dependência
- Persistência com Entity Framework Core + MySQL
- Operações assíncronas (async/await)
- Autenticação e autorização via JWT (JSON Web Token)
- Hash de senhas com BCrypt
- Documentação interativa com Swagger

Projeto desenvolvido para aprendizado de C# e do ecossistema .NET.
